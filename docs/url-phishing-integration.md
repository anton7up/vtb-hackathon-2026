# Подключение фишинговой модели к сайту

## Что подключено

Раздел «Ссылки» в кабинетах клиента и сотрудника использует настоящий классификатор из https://github.com/vadim5222/phishing_attacks . Это отдельная модель от заглушки классов переводов и от Groq/Qwen для анализа рассказа клиента.

Исходная модель: `TfidfVectorizer(analyzer='char_wb', ngram_range=(3, 5), max_features=10000)` + `LogisticRegression`. Анализирует строку URL, не содержимое страницы. Она не доказывает принадлежность магазину/бренду и не проверяет доставку товара. Отдельный [QR-модуль](qr-checker.md) локально читает изображение и распознаёт формат; обычную ссылку можно вручную перенести в «Ссылки», без автоматической загрузки.

Для запуска на существующем Cloudflare Workers перенесены словарь, IDF, коэффициенты и intercept без переобучения. Отдельный Python-сервер, дополнительный API-ключ и Groq для этой проверки не нужны. Версия и SHA-256 исходного `.pkl` записаны в `lib/phishing-model.json`. Реализация JavaScript воспроизводит символьные n-граммы по Unicode code points, TF-IDF, L2-нормализацию и логистическую регрессию. Метки исправлены: `0 = phishing`, `1 = legitimate`.

Веса находятся в серверном `lib/`, а не в `public/`. Бинарный `.pkl`, сторонняя БД, пароли из исходного проекта и CSV в сайт не копировались. Входные URL не запрашиваются по сети и не открываются браузером сервиса.

## API

`POST /api/phishing/check`, с существующей авторизованной сессией, JSON:

```json
{"url":"https://shop.example/"}
```

Ответ содержит `result`: `label` (`phishing` или `safe`), `phishing_score` (0–1, оценка класса 0), `model_version`, `source: "ml"`, `input_type: "url_only"`, `checked_at`. `safe` означает только отсутствие обнаруженных моделью признаков, не гарантию безопасности. Оценки не проверены на калибровку и не являются доказанной вероятностью мошенничества.

Проверяется полный URL с HTTP/S, до 2048 символов; логин/пароль в адресе, некорректные схемы и управляющие символы отклоняются. API защищён существующей авторизацией и same-origin проверками, лимит — 30 валидных запросов в минуту на демо-аккаунт. В БД записывается только хешированный ключ счётчика, URL не сохраняется в истории или состоянии банка. Не вводите ссылки восстановления доступа и адреса с секретами: приложение не обещает обнаружить все секреты внутри текста.

Сбой даёт ошибку проверки, не класс `safe`. Результат никак не снимает защитную паузу, не меняет баланс/реестр и не разрешает перевод. Анализ рискованного URL сам по себе не блокирует весь счёт.

## Проверка эквивалентности Python и JavaScript

Проверено 2000 URL из исходного CSV (фиксированная выборка с seed 42) и 19 дополнительных случаев, включая Unicode, короткие строки, whitespace и длинный путь. Классы совпали во всех 2019 случаях. Максимальная разница оценок на 2000 URL: `6.38378239159465e-16`. Это проверка переноса вычислений, **не независимая оценка качества модели**.

При ручной проверке интерфейса обнаружено ложное срабатывание: `https://example.com/` получает оценку фишинга около `0.9997`. Это поведение исходных весов, а не ошибка переноса. До использования вне прототипа нужны отдельная свежая тестовая выборка, анализ ложных срабатываний и настройка порога/переобучение. Нельзя считать высокую оценку доказательством мошенничества или автоматически блокировать перевод только по этой модели.

Исходный датасет: PhiUSIIL, авторы Arvind Prasad и Shalini Chandra (2024), UCI: https://archive.ics.uci.edu/dataset/967/phiusiil%2Bphishing%2Burl%2Bdataset . Лицензия датасета CC BY 4.0. В исходном репозитории происхождение обученного артефакта не подкреплено журналом обучения. Для самостоятельного распространения артефакта учитывайте условия его автора; проект не объявляет чужую модель собственным обучением.

## Как воспроизвести экспорт при обновлении модели

Python нужен только разработчику для экспорта/сравнения, но не при обычном запуске сайта. Экспорт использует ограниченный загрузчик конкретного sklearn-конвейера, не импортирует код чужого checkout и не должен принимать произвольные модели от посетителей. Ограниченный загрузчик не заменяет изоляцию ОС для недоверенных файлов.

В Python-окружении с совместимыми numpy/pandas/scikit-learn/joblib:

```shell
python -B scripts/export-phishing-model.py --source ../phishing-attacks-reference --samples 2000
node scripts/verify-phishing-parity.mjs
node --test tests/url-phishing.test.mjs tests/auth.test.mjs
```

Путь `--source` — локальная копия репозитория с `backend/main/ml/dataset/phishing_url_model.pkl` и `phishing.csv`. Экспорт обновляет JSON весов и синтетические контрольные примеры; реальные URL для сравнения сохраняются только в игнорируемый `work/`. Не загружайте этот каталог в Git. Обычные `npm run build` и `npm start` используют уже экспортированные веса и не требуют этой копии репозитория.
