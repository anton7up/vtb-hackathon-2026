# Проверка инвестиционного сайта по открытому списку Банка России

Это отдельная проверка репутационного источника, не URL-ML и не решение об оплате.
Она не меняет классы переводов, правила паузы, модель фишинга и снятие наличных.

## Реальные данные

- Описание источника: <https://www.cbr.ru/inside/warning-list/>.
- Документация: <https://cbr.ru/development/warning-list/>.
- OpenAPI Search/DetailInfo: <https://cbr.ru/warninglistapi/swagger>.
- Используем **полный официальный JSON**, не пользовательский поиск: <https://www.cbr.ru/inside/warning-list/black-list-json>.

Формат полной выгрузки отличается от Search в OpenAPI: `{ "RC": [{ "Id", "DT", "Name", "Site", "Sign", "DateUpdate", ... }] }`.
Внешний smoke-тест 30.10.2026 подтвердил формат: 27 613 записей, около 11 МБ. Число и содержимое меняются.
Исходный список не копируется в Git, а загружается сервером из фиксированного официального источника.

Это список компаний/проектов с выявленными признаками нелегальной деятельности на финансовом рынке, включая финансовые пирамиды.
Это **не** закрытая база мошеннических реквизитов ЦБ, не перечень всех фальшивых магазинов, не подтверждение лицензии и не судебное установление мошенничества.

## Что делает проверка

1. Клиент вводит HTTP(S)-URL или домен.
2. Сервер выделяет домен, приводит IDN к ASCII/Punycode и нормализует регистр, конечную точку и один префикс `www.`.
3. Один раз загружает полный официальный список; повторные запросы используют серверную копию до 6 часов.
4. Сопоставляет **точные домены** из `Site`; не ищет подстроку, похожее название компании или общий регистрируемый родительский домен.
5. Возвращает совпавшие официальные причины, номер записи, дату внесения/обновления и дату получения копии.

Пользовательский URL **никогда не открывается** и не передаётся в ЦБ, Groq или Qwen.
Его путь и параметры не входят в ответ. Домены совпадений не становятся кликабельными ссылками.
Кликабельная ссылка ведёт только на официальный список ЦБ.

### Границы сопоставления

`invest.example` совпадает с `www.invest.example`, но не с `pay.invest.example`, `invest.example.evil.test` или `evil-invest.example`.
Кириллица и Punycode одного домена эквивалентны; внешне похожие разные IDN не эквивалентны.
Записи `vk.com/specific-project` и другие адреса с непустым путём, query или fragment **не превращаются в отметку для всего vk.com**: такие scoped-адреса здесь не индексируются.
Это осознанное ограничение: проверка не доказывает отсутствие точной страницы в полном списке.
Перечисленные только дочерние домены не распространяют отметку на весь родительский домен.

## Контракт интеграции

Сервер:

```js
import { createCbrWarningService } from './cbr-warning-service.mjs';
const cbrWarning = createCbrWarningService();
// Один экземпляр на процесс; сохранить в runtime.cbrWarning.
const report = await cbrWarning.checkUrl(body.url);
```

Рекомендуемый защищённый маршрут: `POST /api/cbr-warning` с JSON `{ "url": "example.com" }`.
Нужны существующие сессия клиента, same-origin/CSRF-проверка, ограничение тела и частоты запросов.
Некорректный ввод бросает ошибку `{code:'invalid_url', status:400}`; отсутствие сети возвращает отчёт `unavailable`, а не положительный результат.

```js
{
  status: 'matched' | 'not_listed' | 'unavailable',
  domain: 'example.com',
  source: { name, url, documentationUrl },
  checkedAt: 'ISO timestamp',
  dataFetchedAt: 'ISO timestamp' | null,
  matches: [{ id, name, signs, listedAt, updatedAt, matchedDomain, detailUrl }],
  matchCount: 0,
  message: 'Объяснение клиенту',
  // errorCode только при unavailable; без сетевых адресов и текста внутренних исключений.
}
```

Клиент: `renderCbrWarningCheck(ui, {esc})` из `public/cbr-warning-view.mjs`.
Поля состояния: `cbrUrl`, `cbrBusy`, `cbrError`, `cbrReport`.
Форма `#cbr-warning-form`, поле `#cbr-warning-url`. Отдельный блок в «Ссылках», не замена существующей проверки сайта.

## Ограничения сетевой загрузки

- Единственный URL и origin зашиты в код; редиректы и изменённый конечный URL отвергаются.
- TLS проверяется стандартным Node.js; не отключать `rejectUnauthorized` для VPN.
- Максимум 32 МиБ распакованного тела, 100 000 записей, 15 секунд на загрузку/чтение.
- Проверяются HTTP-статус, JSON content type, UTF-8, структура записей и дубликаты ID.
- Параллельные запросы делят одну загрузку; после ошибки повтор не раньше минуты.
- Просроченная копия после неудачного обновления **не** используется для результата `not_listed` или `matched`. Дата предыдущей копии показана только как диагностическая информация.
- Копия живёт только в памяти процесса: после перезапуска нужна сеть. Для обычного сервера позднее можно добавить атомарный файловый кэш с проверкой срока и схемы.

## Проверка

```powershell
node --test tests/cbr-warning-list.test.mjs tests/cbr-warning-view.test.mjs tests/cbr-warning-api.test.mjs
```

Тесты детерминированы, не обращаются к реальным подозрительным сайтам: используются вымышленные домены `.example` и внедряемый `fetchImpl`.
Проверены нормализация, IDN, spoof-границы, scoped-страницы, ложный безопасный ответ при сбое, таймаут, размер, редиректы, кэш, параллелизм и HTML-escaping.
Отдельные API-тесты проверяют авторизацию/CSRF, обе роли, лимит 6 проверок в минуту на аккаунт, отсутствие записи URL и неизменность банковских данных.
Ручной реальный smoke должен обращаться только к официальной выгрузке ЦБ, не к указанным там сайтам.

Отсутствие совпадения всегда нейтрально: **«Это не означает, что сайт или инвестиции безопасны»**.
